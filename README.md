## 📌 Overview

The QR Code Generator is a modern web application designed to simplify QR code creation for websites, text, and search queries.

Built entirely with frontend technologies, the application delivers instant QR generation without requiring any backend server, database, or API integration.

Users can generate, scan, and download QR codes effortlessly across desktop and mobile devices.

## ⚙️ QR Generation Engine

The application processes user input and converts it into a scannable QR code instantly.

### Workflow

- Enter text, URL, or keyword
- Validate and format the input automatically
- Generate QR code using QRCode.js
- Display QR instantly on screen
- Download or scan directly

---

## 📷 Smart Input Processing

The system intelligently handles different types of user input.

### Features

- Automatically detects valid URLs
- Supports custom text and messages
- Converts keywords into searchable queries
- Prevents invalid QR generation

## 🧪 Local Setup

### Clone the Repository

```bash
git clone https://github.com/rishavSE/Qr-generator.git
cd Qr-generator
```

### Run the Application

Since this is a static web application, no installation is required.

Simply open:

```text
index.html
```

in your browser.

#### Windows

```bash
start index.html
```

#### macOS

```bash
open index.html
```

#### Linux

```bash
xdg-open index.html
```
